About this demo

How it works

  • Text gets cleaned and turned into TF-IDF features over single words and word pairs.
  • A class-balanced logistic regression scores those features. Each bar is a word’s TF-IDF weight times its coefficient.
  • Anything under 60% confidence is labeled uncertain, same as the Python report.

How I checked the port

  • The JavaScript scores match scikit-learn to within 0.0000003 across 144 test strings.

Known limits

  • It only learned from 136 labeled reviews, so the vocabulary is small and wording it hasn’t seen stays close to neutral.
  • The English stop-word list removes “not”, so “not good” mostly reads as “good”. That’s the first thing I’d fix.
  • The suspicious-review flags are simple rules, not real fraud detection.
