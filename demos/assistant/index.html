AI leasing assistant

I built a WhatsApp assistant for a property-management company, and it’s running in production. I can’t show the real system or its conversations, so this is a scripted replay of how it works, with the chat, the agent’s tool calls, and a team view side by side.

The real architecture

  1. WhatsApp bridgeNode.js service that sends and receives messages.
  2. FastAPI backendPython service running the agentic Claude tool-use loop.
  3. PostgreSQLLeads, viewings, maintenance and deal stages, through SQLAlchemy.
  4. Discord admin botAlerts the team and handles human-in-the-loop escalation.
  5. React dashboardReact/Vite view of the lead funnel and operations.
  6. DeploymentDocker Compose on a VPS behind an HTTPS reverse proxy.

About this demo

What’s real

  • Tool names, parameters, and deal stages come from the production code.
  • Two rules carry over: prices always come from a tool, and money or legal questions go to a person.

What’s scripted

  • No AI model runs on this page. I wrote the messages, reasoning notes, and tool results for the demo.
  • The dashboard is a rough sketch, not the production UI.
  • It has no client data or real conversations.

Design decisions

  • The model never does rent math. The server calculates quotes so it can’t make up a price.
  • Handing off to a person is just another tool call, so it gets logged like everything else.
  • Deal stages live in the database, so the scheduled follow-ups and the dashboard stay in sync.
