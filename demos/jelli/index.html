Jelli

It’s hard to score an album out of 10 from nothing. Jelli takes a rough score, then has you compare the album against others you’ve ranked until it finds the right spot.

    About this demo

    The algorithm

    • Albums sort by score first. Comparisons only happen between albums with the same score, using a binary search.
    • That’s about log₂(n) questions, so a long list doesn’t slow it down much.
    • “Haven’t heard it” takes that album out of the search but keeps its place. “Too close to call” puts the new album right below it.

    How it relates to the app

    • This is a JavaScript port of TiebreakPlacement from the app’s TypeScript engine, including skip and too-close.
    • It logs each pick like the app does. The app’s Elo view replays that log.
    • The starting list is sample data, and nothing gets saved.

    The full app

    • Built with Eddie Guan in Expo/React Native and TypeScript, for iOS, Android, and web.
    • Runs on Supabase with row-level security and no custom server.
    • Gets music data from iTunes, Last.fm, and Deezer.
